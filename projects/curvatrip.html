Overview

CurvaTrip is the conversational AI behind the chat and voice screens of the CurvaTrip flight-booking app. A visitor can type or speak a request in plain language — “cheapest flight to Paris next weekend for two” — and the agent searches a live GDS, filters by learned preferences, prices the fare, and walks the user to payment.

The agent exposes 32 tools over flights, bookings, trip planning and notifications. Language handling is a first-class concern: an LLM classifier picks the reply language between English, French, Arabic and Tunisian Derja, with Derja written from a real phrasebook rather than machine-translated Modern Standard Arabic.

Voice runs through a Gemini Live bridge with barge-in, so a caller can interrupt mid-sentence. Voice replies carry the same flight cards and trip plans as the chat and persist to the same history.

What it does

  • 32 agent tools: flight search and refinement, fare rules, branded fares, cheapest-dates, booking, cancellation, price alerts, trip planning, weather, currency and support
  • Booking is gated behind payment — the API emits a checkout event so the app opens the SATIM gateway, and a booking that cannot be ticketed degrades to a held PNR instead of failing outright
  • Day-by-day trip plans with photos, price bands, distances and tips, built from disk-cached catalogs to keep plan generation responsive
  • Realtime voice over a Gemini Live bridge (PCM16, 16 kHz in / 24 kHz out) with barge-in support
  • SQLite for development, Oracle 11g in production, bridged by a hand-written dialect-translating data layer
  • 17 golden behaviour scenarios run as an eval harness — language choice, payment gating, guest isolation, round-trip legs, multi-city and more

Notes & decisions

Sticky routing was not optional

Flight catalogs live in RAM between turns, so a request that lands on a different instance loses the user's context. nginx hashes on user id plus remote address to keep a session pinned. An early config capped failover retries at 3 while running 16 instances — users hashed to a stopped port failed until the retry count matched the pool size.

Derja is a dialect, not a translation

Machine-translating Modern Standard Arabic produces text Tunisians do not speak. The reply language is chosen by an LLM classifier and Derja responses are written from a dedicated phrasebook, in both chat and voice.

Built on an open-source runtime

The agent loop, tool registry and memory come from Hermes Agent (NousResearch, MIT). The travel product — tools, planner, language stack, voice bridge, server and app — is my own code on top of it.
