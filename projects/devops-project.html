Overview

A Spring Boot microservice built to carry a complete DevOps pipeline rather than to be a large application. The point of the exercise was everything around the code: tests, logging, containers, metrics and dashboards.

The service is packaged with a Dockerfile and docker-compose, instrumented for Prometheus scraping, and visualised in Grafana. An Angular 16 frontend consumes the API.

What it does

  • Spring Boot service (tn.esprit.devops_project) built with Maven
  • Unit tests with JUnit and Mockito
  • Log4j logging configuration
  • Dockerfile plus docker-compose for the full stack
  • Prometheus metrics scraping with a Grafana dashboard
  • OpenAPI specification checked into the repository
  • Angular 16 frontend, built in a two-person collaboration
