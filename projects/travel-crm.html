Overview

An enterprise travel CRM where the reporting layer is a conversation. Instead of clicking through dashboards, a manager asks a question and an 8-agent system decides which specialist should answer it: SQL, Analyst, Forecast, Anomaly, Segmentation, Hotel, Flight, or the Orchestrator that routes between them.

The agents run on LangGraph with DeepSeek through OpenRouter, over an Oracle 11.2g database exposed by 52 FastAPI endpoints. Answers stream back over SSE so long analyses render progressively instead of blocking.

The Angular 17 dashboard renders the results as interactive charts and maps, and a separate ingestion path parses hotel contract PDFs with OCR.

What it does

  • 8 specialised agents coordinated by an orchestrator, each with its own tools and prompt
  • 52 REST endpoints over Oracle 11.2g
  • SSE streaming so multi-step analyses appear as they are produced
  • Angular 17 dashboard with interactive charts and real-time route maps
  • Hotel contract PDF parsing with OCR
  • Amadeus API integration for flight and fare data

Notes & decisions

Routing beats one big prompt

A single agent holding every tool degrades as the toolset grows. Splitting the work into specialists behind an orchestrator keeps each prompt small and makes a wrong answer traceable to one agent.
