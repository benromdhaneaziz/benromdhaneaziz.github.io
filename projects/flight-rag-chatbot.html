✈️Flight Invoice RAG Chatbot

Retrieval-augmented Q&A over invoice data

GitHub ↗

Overview

A Streamlit chatbot that answers questions about flight invoices and profit figures. Invoice CSV data is embedded into a local ChromaDB collection, retrieved semantically per question, and passed to the model as context.

Keeping the vector store local means the data never leaves the machine — only the retrieved snippets reach the LLM.

What it does

  • RAG pipeline over ChromaDB with all-MiniLM-L6-v2 HuggingFace embeddings
  • Groq running Llama 3 8B for fast contextual answers
  • Flight invoice CSV data ingested into the vector store
  • Streamlit interface
