🧠Knowledge Graph for Project Management

BERT + RGCN link prediction

GitHub ↗
2Recommender variants

Overview

A graph-based recommendation system for project risk management. The knowledge graph is built from PMI standards, PMBOK 6 and 7, a risk-management glossary and real case studies, so recommendations are grounded in the discipline's own literature.

Two recommenders were built and compared: one using BERT embeddings with a custom link predictor, and one combining BERT embeddings with a Relational Graph Convolutional Network for richer structural context before the same predictor.

What it does

  • Knowledge graph assembled from PMI standards, PMBOK 6 & 7 and case studies
  • BERT embeddings for semantic representation of graph entities
  • RGCN over the relational graph for structure-aware embeddings
  • Custom link-prediction head driving the recommendations
  • Pinecone vector index for similarity search
  • GPT-4 Mini for natural-language question answering over the graph
