Overview

Hotel contracts arrive as PDFs, Word files and spreadsheets, each laid out differently, and every rate in them has to be read by hand before a stay can be quoted. This platform reads them automatically: an LLM extraction pipeline with an OCR fallback turns a contract into a normalized Oracle schema of 17 tables — seasons, rooms, rates, supplements, reductions, taxes, offers, cancellation and payment rules.

Pricing is deliberately kept away from the model. A deterministic pure-Python engine prices any stay from the extracted tables and pre-builds a full pricing matrix per contract, so a quote is reproducible and auditable rather than something a language model guessed.

Hermes, the in-app assistant, sits on top with 12 tools. It answers questions about a contract, computes prices, finds gaps in the extracted data and proposes field edits — always behind a dry-run then confirm flow, so nothing is written to a contract without review.

What it does

  • Dual-path extraction pipeline (V1 + V2) with an OCR fallback for scanned contracts, driven by a 45 KB JSON schema
  • Deterministic pricing engine — no LLM in the pricing path — with matrix build, Excel export and a per-stay breakdown
  • Assistant with 12 tools: price calculation, hotel lookup, contract sections, field descriptions, gap finding, autofill suggestions, rescan and matrix rebuild
  • Row-level multi-tenancy: the tenant id comes from the JWT and is injected into every Oracle query, with per-tenant document cabinets
  • Oracle-backed async upload queue using FOR UPDATE SKIP LOCKED with a worker pool, so batch ingests do not block the API
  • Parse-quality scoring, missing-field detection, audit log and per-event billing for uploads and rescans
  • Production guards: the app refuses to boot on a default JWT secret, and API docs are disabled outside development

Notes & decisions

Why pricing never calls the model

A quote that cannot be reproduced cannot be sold. The LLM's job ends once the contract is structured; every price after that comes from plain Python over the extracted tables, which makes each figure traceable to a rule and a row.

Tenant isolation by construction

Rather than filtering in the service layer, the tenant id from the JWT is threaded into the data layer and applied to every query — around 370 call sites — so a missing filter is a compile-time-visible omission, not a silent leak.
