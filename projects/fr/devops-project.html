Service Spring Boot avec chaîne complète

GitHub ↗

Aperçu

Un microservice Spring Boot conçu pour porter une chaîne DevOps complète plutôt que pour être une grosse application. Tout l'intérêt de l'exercice tient à ce qui entoure le code : tests, journalisation, conteneurs, métriques et tableaux de bord.

Le service est packagé avec un Dockerfile et docker-compose, instrumenté pour être scrapé par Prometheus et visualisé dans Grafana. Un frontend Angular 16 consomme l'API.

Ce que ça fait

  • Service Spring Boot (tn.esprit.devops_project) construit avec Maven
  • Tests unitaires avec JUnit et Mockito
  • Configuration de journalisation Log4j
  • Dockerfile et docker-compose pour l'ensemble de la stack
  • Collecte de métriques Prometheus avec tableau de bord Grafana
  • Spécification OpenAPI versionnée dans le dépôt
  • Frontend Angular 16, en collaboration à deux
