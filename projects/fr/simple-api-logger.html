🔌Simple API Logger

Journalisation FastAPI avec tableau de bord

GitHub ↗
3Endpoints d'API
5sRafraîchissement

Aperçu

Un service REST léger qui journalise chaque requête qui le traverse et affiche le résultat sur un tableau de bord en direct. Un middleware maison capture la méthode, l'URL, le corps, le code de statut et le temps de réponse de chaque appel et les stocke dans SQLite.

Il embarque un interrupteur de panne volontaire : envoyer un message « trigger500 » provoque une division par zéro, ce qui permet d'éprouver la gestion et la journalisation des erreurs à la demande plutôt que de l'espérer.

Ce que ça fait

  • POST /api/log pour enregistrer une entrée, GET /api/logs avec filtres de statut et de limite, GET /api/stats pour les statistiques
  • Statistiques : total des requêtes, succès contre erreurs, temps de réponse moyen et endpoints les plus sollicités
  • Middleware ASGI maison qui capture chaque requête, y compris les échecs
  • Tableau de bord Bootstrap 5 / Jinja2 rafraîchi toutes les 5 secondes
  • Mécanisme trigger500 pour tester volontairement les chemins d'erreur
