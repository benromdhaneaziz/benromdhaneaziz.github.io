Aperçu

Une application ASP.NET Core de reporting pharmaceutique, développée pendant mon stage chez Prosper Us. Elle suit le patron MVC et Razor Pages avec Entity Framework Core pour la persistance et les migrations.

La solution se découpe en trois projets : l'application web principale et deux modules dédiés, MedicalReport et ReportSheet, qui génèrent les documents structurés que les pharmaciens déposent.

Ce que ça fait

  • ASP.NET Core MVC avec Razor Pages
  • Entity Framework Core avec migrations code-first
  • Module MedicalReport pour les documents médicaux structurés
  • Module ReportSheet pour les feuilles de rapport pharmaceutique
  • Solution Visual Studio en trois projets
